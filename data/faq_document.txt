QA MEMORY RAG — BASE DE CONOCIMIENTO FICTICIA

Esta fuente describe antecedentes y cobertura de una aplicación bancaria completamente ficticia. Cada registro es una unidad semántica autocontenida. Los IDs, servicios, equipos, operaciones y relaciones existen sólo para este proyecto académico. El sistema debe recuperar evidencia y abstenerse cuando una pregunta no encuentre respaldo suficiente. Ningún dato pertenece a personas, bancos, clientes, incidentes o plataformas reales.
